Sample docker image used by @jeanlaurent for testing various docker features.
It is a simple nginx app that display a nice whale riding waves.
It is a simple container based application that is meant to be used as guinea pig for various docker technology

`docker run -p 8080:8080 jeanlaurent/whale`
open your browser to [http://localhost](http://localhost:8080)
